# A4 – [Topic]

## Objective

The objective of this assignment is to design and create a mount for a brushed motor. In particular, making a rigid mount while maintaining a safety factor of 3. This will be done through calculations and visualizations with the end goal being a CAD model of the design along with a multiview drawing. This assignment will teach the ability to design around given parameters as well as incorporating a design with a real life product.
