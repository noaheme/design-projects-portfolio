## Objective

Project A11 is a continuation of project A10 which will build on the leadscrew, bearing, and crosshead designs adding in a motor and other features to create a realistic tensile tester. This project required a motor be selected and mounts be created to support that motor. Mounts that would need to be created through mathematic analysis and CAD design. Then we were to run a design analysis on the clamp to make sure it met a safety factor of 4. Other notable constraints for the assignment include a purely mechanical design, 2kN load capacity, given speed range, and form factor.
