# A6 – Bracket Drawing

## Objective

This project is an expansion on A5. We will be taking the bracket design and calculations from A5 and creating a CAD design and drawing of the bracket. This along with reflecting on the design process will bring together the past 2 weeks of work into one complete design cycle giving an idea of what the engineering design process looks like.

## Analyze

Part 1: Parametric Design

The first part of this project was to parametrically design the bracket from problem A5. In A5 we determined the minimum values that could be used and in A6 we will be taking those values and expanding them to make a logical design. I quickly realized that my chosen values for A5 were "minimums" for a reason when designing and seeing that the design would be so small some parts would rub or not work at all.

I chose to extend the lengths to a 3x3x2 in order to clearly fit the minimum values as well as look good with the pin that would be holding the strap. The entire design was designed parametrically.
